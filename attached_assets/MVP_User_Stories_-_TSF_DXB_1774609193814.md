MVP User Stories - TSF DXB

These user stories define the minimum viable product (MVP) requirements for the website's launch.

1. Discovery & First Impression

As a website visitor from Dubai

I want to see a clear headline and high-quality background image of people paddling immediately upon loading

So that I know exactly what the club offers and feel inspired to join.

Acceptance Criteria: Hero section has a 1-line headline, a subheadline, and a primary CTA above the fold on mobile.

2. Navigation & Wayfinding

As a mobile user

I want a simple hamburger menu with clear, distinct categories (Lessons, Rentals, Club)

So that I can easily find pricing and locations without getting lost in complex menus.

Acceptance Criteria: Navigation contains no more than 5 top-level links.

3. Session Evaluation

As a beginner paddler

I want to view "Session Cards" that clearly list duration, group size, included equipment, and skill level

So that I can confidently choose the right activity without having to call for basic details.

Acceptance Criteria: Session UI utilizes a card-based layout with bulleted details and clear pricing.

4. Trust & Safety Validation

As a parent booking for my family

I want to read a brief section on safety briefings, age limits, and coach qualifications

So that I feel secure knowing the club operates professionally.

Acceptance Criteria: Homepage includes a dedicated "Safety & Community" section.

5. Frictionless Conversion

As an interested customer

I want to click a single button to launch WhatsApp

So that I can quickly ask a question or book a session directly from my phone.

Acceptance Criteria: "WhatsApp Us" buttons are present in the Hero, Footer, and Session cards, linking correctly to the provided number.
