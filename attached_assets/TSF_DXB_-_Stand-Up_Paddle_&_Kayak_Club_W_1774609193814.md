TSF DXB - Stand-Up Paddle & Kayak Club Website

This repository contains the code for the TSF DXB watersports club website. The design and UX are based on extensive research of top-performing global and local SUP clubs, prioritizing mobile-first navigation, transparent pricing, community building, and frictionless WhatsApp booking.

Quick Start

Install dependencies:

npm install


Run the development server:

npm run dev


Open your browser:
Navigate to http://localhost:3000

Project Structure

/components: Reusable UI elements (Navbar, Footer, SessionCard).

/app or /pages: Main page routes (Home, About, Activities).

/public: Static assets (images, logos).

Key Features

Mobile-First Design: Optimized for users discovering the club via Instagram/TikTok.

WhatsApp Integration: Primary booking flow routes directly to WhatsApp (+971544667458) for fast, personalized customer service.

Card-Based UI: Activities are broken down into easy-to-read cards outlining duration, price, and skill level.
